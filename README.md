# CARE Wildlife Sanctuary Database System

A comprehensive relational database system engineered to manage complex wildlife sanctuary operations, medical logs, staff allocations, and reservations. Developed as a university coursework project.

## Overview
This project centralizes tracking for sanctuary wildlife, ensuring strict data integrity and structural efficiency. It models core entities—including animals, species classifications, specialized veterinarians, staff members, medical logs, and operational schedules.

## Key Contributions & Responsibilities
* **Database System Architecture:** Led the end-to-end design, normalization, and SQL implementation as Group Leader.
* **Entity-Relationship Modeling:** Established core entities, attributes, and data types, aligning the ERD with rigorous business rules.
* **Anomaly Resolution & Normalization:** Eliminated data redundancies by extracting species and veterinarian records into dedicated tables, resolving potential update and deletion anomalies.
* **Data Integrity:** Implemented strict constraints, structured master SQL scripts, and optimized schema design.
  
## Tech Stack & Skills
* SQL / Relational Database Management Systems (DBMS)
* Entity-Relationship Diagramming (ERD)
* Data Normalization (up to 3NF)
* Technical Leadership & Project Management
